Salty

A Solidity-like language that transpiles to Solidity.

Salty adds ergonomic features on top of Solidity — like switch, which lowers to if / else if / else — and emits clean, compilable Solidity. It ships as a small Go CLI and this pure-HTML site: no framework, no build step.

Install

go install github.com/bitcoinbrisbane/salty/cmd/salty@latest

Use

salty transpile Counter.salty
