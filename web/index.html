Salty

A Solidity-like language that transpiles to Solidity.

Salty adds ergonomic features on top of Solidity — like switch, which lowers to if / else if / else — and emits clean, compilable Solidity. It ships as a small Go CLI and this pure-HTML site: no framework, no build step.

Install

go install github.com/bitcoinbrisbane/salty/cmd/salty@latest

Use

salty transpile Counter.salty

The decimal type (SIP-2)

Solidity has no usable decimal type, so contracts scale integers by hand. Salty makes it a first-class type: decimal / decimal(N) lower to uint256, and decimal literals are scaled for you.

// Salty
decimal price = 1.5;      // decimal(18)
decimal(8) feeRate;

// Solidity
uint256 price = 1500000000000000000;
uint256 feeRate;

Dynamic arrays (SIP-3)

T[] dynamic arrays with a[i], a.length, a.push(x) and a.pop(). Element types lower by the usual rules.

// Salty
uint[] ids;
decimal(18)[] prices;
ids.push(id);

// Solidity
uint256[] ids;
uint256[] prices;
ids.push(id);

Array sort (SIP-4)

a.sort() lowers to LibSort.sort(a), and Salty injects a generated insertion-sort library once — only when sort is used.

// Salty
scores.sort();

// Solidity
LibSort.sort(scores);   // + a generated library LibSort injected once

Contributing (SIPs)

Language changes are proposed as Salty Improvement Proposals, modelled on Ethereum's EIPs: open a GitHub issue with the SIP proposal template, then submit the spec as sips/sip-N.md. See the SIP index.
