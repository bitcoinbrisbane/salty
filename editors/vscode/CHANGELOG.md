# Changelog

## 0.1.0

- Initial release.
- Extension icon (salt shaker), generated reproducibly from `icon/generate_icon.py`.
- Syntax highlighting for `.salty` files (keywords, types, `decimal` literals
  per SIP-2, strings, comments).
- `Salty: Transpile to Solidity` command that runs the `salty` CLI and opens the
  Solidity output.
- `salty.cliPath` setting for locating the CLI.
